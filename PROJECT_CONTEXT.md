Last verified 2026-10-04 from the shallow clone of `main` at `1c2aa83`.

## Architecture
- **App:** `uploads/app-yatla.html` is a self-contained static HTML/CSS/JS app. It embeds the 3,773-entry merged book pack and a separate 668-entry general-search dictionary; UI languages are English, Turkmen, and Russian. There is no framework-based frontend or backend.
- **Content pipeline:** `content/data/*.json` → `content/tools/merge_packs.py` → tracked `content/merged/yatla-all.json` → AJV validation/build via `content/tools/validate.js` and `build.js`. The browser loader is `content/loader/yatla-content.js`; generated bundles go to `content/build/`. `tests/` contains jsdom baseline and integration suites.
- **Persistence/services:** browser `localStorage` and IndexedDB only. Authentication is local/demo authentication, not server-backed. No database service, external API credentials, or environment variables were found. No `.env` file is present.
